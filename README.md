## Git Practice Notes

### What is Git?
Git is a version control system. It helps us track changes in files.

### What is GitHub?
GitHub is an online platform where we can store and share our projects.

### Useful Git Commands

- git init: Creates a new Git repository.
- git clone: Copies a repository to the computer.
- git status: Shows the current status of files.
- git add: Adds changes for commit.
- git commit: Saves changes in Git.
- git push: Uploads changes to GitHub.
- git pull: Downloads the latest changes.

### Branch
A branch allows us to work on changes separately without directly changing the main branch.

### Pull Request
A Pull Request is used to propose changes from one branch to another branch.
